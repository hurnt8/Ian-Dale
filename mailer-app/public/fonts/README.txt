Police de marque HelvNeueOrange
================================

Déposez ici les fichiers de la police (format web). Noms attendus par public/css/app.css :

  HelvNeueOrange-Regular   -> graisse 400
  HelvNeueOrange-Medium    -> graisse 500/600
  HelvNeueOrange-Bold      -> graisse 700/800

Formats acceptés (dans cet ordre de préférence) : .woff2, .woff, .ttf, .otf.
Un seul format par graisse suffit. Exemple minimal : HelvNeueOrange-Regular.ttf
et HelvNeueOrange-Bold.ttf.
- Tant que ces fichiers sont absents, l'interface utilise Inter : aucune erreur, aucun changement visible.
- Après ajout, videz le cache du navigateur (Ctrl+F5) : le CSS est versionné (app.css?v=6).
